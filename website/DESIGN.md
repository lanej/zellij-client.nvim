# Documentation design

Readers need to install the client, identify the intended session, and handle asynchronous outcomes safely. Keep the overview short and put runnable Lua examples beside the API they demonstrate. Separate client lifecycle from protobuf representation and runtime compatibility.

Use Starlight's responsive sidebar, search, theme controls and reading column. Retain readable code with horizontal scrolling inside code blocks; the page itself must not overflow. Keep text in system fonts and use the restrained green accent from lanej.io. Mobile navigation and keyboard search must remain usable.

Every reference page has one clear title, useful headings and a source-edit link. Show uncertainty and compatibility limits near the operations they constrain. Avoid marketing panels, decorative artwork and unsupported performance claims.
